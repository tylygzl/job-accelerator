求职加速器 - 朋友试用说明

先说结论：你不用安装 Python，不用运行后端，也不用填写大模型 API。
这个版本已经默认连接云端服务，直接加载 Chrome 插件即可使用。

一、你会拿到什么

请使用这个压缩包：

release/plugin-cloud.zip

注意：不要把这个压缩包公开发到网上。它是临时朋友测试包，里面带有访问云端后端的令牌。
也不要把整个 release 文件夹发出去，里面可能有历史测试包；只发 plugin-cloud.zip。

二、安装插件

1. 解压 plugin-cloud.zip。
2. 打开 Chrome，进入：

chrome://extensions/

3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的 plugin-cloud 文件夹。
6. 安装或重新加载插件后，刷新一次已经打开的 BOSS 页面。

注意：选择文件夹，不是选择 zip 压缩包。

三、使用前先在 BOSS 页面筛选

插件不会替你选择城市、薪资、经验、学历、行业这些 BOSS 筛选条件。

你需要先在 BOSS 页面自己选好，例如：

- 城市
- 岗位关键词
- 薪资范围
- 工作经验
- 学历要求
- 公司行业

插件负责的是：在你筛选后的岗位列表里，继续帮你读取 JD、匹配简历、达标后自动沟通。

四、上传简历

1. 打开 BOSS 岗位搜索页。
2. 点击浏览器右上角“求职加速器”插件。
3. 上传文字版 PDF 简历。
4. 如果 PDF 解析失败，展开“没有 PDF？粘贴或修改简历文本”，手动粘贴简历文本。

说明：

- 文字版 PDF 一般可以解析。
- 扫描件、图片版 PDF 可能无法解析。
- 简历内容和岗位 JD 会发送到云端后端做匹配，请只在你接受这个测试前提时使用。

五、开始投递

建议第一次测试这样设置：

- 今日目标：3
- 匹配度：70%
- 模式：快速投递

快速投递：

- 主要走本地规则匹配
- 不等待大模型
- 更适合批量海投

智能投递：

- 云端辅助判断
- 可能更慢
- 模型失败时会走本地兜底，不应该卡住主流程

六、正常表现

点击“快速投递”后，正常链路应该是：

扫 JD
→ 匹配达标
→ 自动点击“立即沟通”
→ BOSS 弹出确认框
→ 自动点击“留在此页”
→ 继续处理下一个岗位

七、HR 回复助手

这个版本在同一个插件里加了 HR 回复助手，不需要安装第二个插件。

使用方式：

1. 打开 BOSS 消息页。
2. 点击插件里的“检查 HR 回复”。
3. 看到待回复列表后，点击某条“处理回复”。
4. 插件会进入对应会话，读取最近聊天上下文，生成回复草稿并填到输入框。
5. 请你自己检查内容，再手动点击发送。

注意：

- 插件不会自动发送 HR 回复。
- 如果正在海投，点击“处理回复”会先暂停海投。
- 处理完 HR 回复后，不会自动恢复海投，需要你手动重新开始。
- 如果后端判断风险高、证据不足或需要人工接管，插件不会填输入框。

八、如果卡住了，怎么反馈

先看插件侧边栏顶部状态：

- 当前页面模式
- 当前任务
- 最近一步
- 下一步建议

如果愿意帮忙排查，可以展开“开发调试状态”，把里面的任务状态、lastError 和 lastRequestId 一起截图。

请截图两张：

1. BOSS 当前弹窗或页面状态
2. 插件右侧面板提示

不用截图你的完整简历、聊天隐私或手机号。

九、常见问题

如果插件打不开：

- 确认加载的是 plugin-cloud 文件夹。
- 到 chrome://extensions/ 里点“重新加载”。
- 刷新 BOSS 页面后再点插件。

如果提示云端连接失败：

- 可能是云端服务暂时不可用。
- 可能是当前网络访问不了临时 HTTP 服务。
- 联系分享插件的人检查服务器。

如果 PDF 解析失败：

- 换文字版 PDF。
- 或者直接粘贴简历文本。

如果自动投递卡在某个弹窗：

- 先不要连续乱点。
- 截图 BOSS 弹窗和插件面板提示。
- 这通常是 BOSS 页面按钮文案或 DOM 结构变化导致的。

十、风险说明

这个工具是学习项目和小范围试用版，不保证适配 BOSS 的所有页面状态。
请控制投递数量，避免高频操作影响账号安全。
最终是否投递、是否继续沟通，由使用者自己负责。
