Job Accelerator 朋友试用说明

先说结论：这个工具不是全自动群发。它会帮你筛岗位、生成开场白、打开沟通页并填入内容，最后发送仍然需要你自己确认。

使用前建议先看 README.md 里的免责声明。遇到启动失败、后端连不上、LLM 超时，可以看 docs/troubleshooting.md。

1. 解压压缩包

把整个压缩包解压到一个普通目录，例如桌面或 D 盘。不要只单独拖出 plugin 文件夹。

2. 启动后端

双击 start_server.bat。

第一次运行时，如果目录里没有 .env，脚本会自动复制 .env.example 生成 .env，然后停下来。

打开 .env，至少填写：

LLM_PROVIDER=你的模型服务商
LLM_API_KEY=你的 API Key
LLM_MODEL=你的模型名或 endpoint id

如果只是想先看本地兜底效果，可以保持：

LLM_PROVIDER=none

填好后再次双击 start_server.bat。窗口里看到 http://127.0.0.1:8000 就保持窗口不要关。

3. 检查后端是否正常

浏览器打开：

http://127.0.0.1:8000/health

能看到 ok=true，说明后端启动成功。

4. 加载 Chrome 插件

打开 Chrome：

chrome://extensions/

打开右上角“开发者模式”，点击“加载已解压的扩展程序”，选择解压目录里的 plugin 文件夹。

5. 使用流程

先在 BOSS 直聘页面自己设置好城市、岗位、薪资、经验、学历等筛选条件。

然后点击浏览器右上角插件图标：

- 粘贴简历
- 设置匹配度阈值
- 设置排除关键词，例如 培训,销售,保险
- 点击保存配置
- 回到 BOSS 搜索页开始分析

6. 看到结果后怎么用

高于阈值的岗位会生成开场白。你可以点击“去沟通”，插件会进入沟通页并把开场白填进去。

最后一步发送需要你自己确认。这个设计是为了避免误发和账号风险。

7. 常见问题

如果 start_server.bat 卡在安装依赖，通常是网络慢。换一个稳定网络后重新双击。

如果插件提示后端连接失败，确认 start_server.bat 的黑色窗口还开着，并检查 http://127.0.0.1:8000/health。

如果 BOSS 页面刷新或岗位列表异常，先减少单次分析数量，等页面稳定后继续。

不要把 .env 发给别人，里面可能有你的模型 API Key。
