# BOSS 页面稳定性实测清单

这个清单用于把“我本机能跑”升级成“不同电脑和页面状态下也比较稳”。

## 电脑和网络

- Windows 10 + Chrome 最新版
- Windows 11 + Chrome 最新版
- 不开代理，LLM_PROVIDER=none，本地兜底可用
- 开代理或直连模型 API，`/health` 显示 `api_key_configured=true`
- 首次双击 `start_server.bat` 能创建 `.env`
- 填好 `.env` 后再次双击能启动 `http://127.0.0.1:8000`

## BOSS 页面状态

- 搜索页首次进入，左侧有岗位，右侧有详情
- 搜索页已经筛选城市、岗位、薪资、学历
- 已沟通过岗位从列表消失后，继续扫描只分析新增岗位
- 左侧列表下滑后，继续扫描能去重
- 单条详情页 `/job_detail/` 可以分析当前详情
- 后端未启动时，插件提示用户启动后端，而不是静默失败
- LLM 超时或 500 时，卡片显示可理解的失败原因

## 判定标准

- 不要求一次扫完所有岗位。
- 每批扫描后，面板统计能解释“当前可见 / 本次累计 / 新增 / 缓存 / 待请求”。
- 页面出现 BOSS 刷新或列表异常时，插件不能无限重复请求同一批岗位。
- 达标岗位点击「立即沟通」后，能自动识别 BOSS 弹窗并点击「留在此页」；如果识别失败，插件应暂停并提示手动处理，不能继续误点。
